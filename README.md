6. Fine-tuning моделей с LoRA — эффективное дообучение LLM
Набор скриптов для тонкой настройки языковых моделей с использованием LoRA (Low-Rank Adaptation) на CPU и GPU.

🔧 Стек технологий:

PyTorch — основа для обучения с поддержкой CUDA и CPU

HuggingFace Transformers — загрузка предобученных моделей и токенизация

PEFT (LoRA) — эффективное дообучение без полной перенастройки всех весов

bitsandbytes — 4-битное квантование для экономии памяти (только для GPU)

Python 3.12+ с кроссплатформенной поддержкой (Windows, macOS, Linux)

✨ Ключевые особенности:

Кроссплатформенность: работает на Windows (GPU/CPU), macOS (CPU через Metal) и Linux (GPU/CPU)

Гибкая настройка: поддержка CPU, GPU и автоматического выбора устройства (--device auto|cpu|cuda)

Разные форматы датасетов: JSON/JSONL с полями text, instruction/output, prompt/completion

Оптимизация для слабого железа: уменьшение batch size, градиентное накопление, отключение 4-bit на CPU

Чистый код: подробные комментарии, примеры запуска для разных конфигураций

Примеры моделей: DialoGPT-small, distilgpt2, gpt2, tiny-gpt2 для быстрого тестирования и отладки

🎯 Решаемые задачи:

Дообучение моделей на собственных данных без необходимости в мощном GPU (работает даже на CPU)

Создание специализированных AI-ассистентов под узкие домены (техподдержка, консультации, генерация контента)

Эксперименты с LoRA для изучения техник параметрически-эффективного обучения

Быстрое прототипирование и тестирование новых идей на CPU перед запуском на GPU
